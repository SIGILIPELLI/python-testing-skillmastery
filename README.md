# Python Testing Mastery Path

A free, structured, module-wise software testing training program using Python — entry level to master level, covering manual QA fundamentals and test automation, with runnable code in every module and a hands-on project at the end of each level.

**Live site:** https://sigilipelli.github.io/python-testing-mastery-path/

## Contents

- **Level 1 · Entry** — manual testing fundamentals, test case design, defect lifecycle, pytest & Selenium basics
- **Level 2 · Intermediate** — Page Object Model, API testing, mocking, reporting, parallel execution
- **Level 3 · Advanced** — Playwright, BDD, Robot Framework, CI/CD, performance and mobile testing
- **Level 4 · Master** — test architecture, contract testing, quality gates, QA strategy

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
