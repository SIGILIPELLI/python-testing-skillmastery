# Level 1 · Entry <span class="level-badge">Foundations</span>

Goal: understand what software testing actually is, be able to design and
document test cases and defect reports like a working QA engineer, and write
your first automated tests in Python with pytest and Selenium.

## Modules

1. [What Is Software Testing?](01-what-is-software-testing.md)
2. [Test Case Design & Documentation](02-test-case-design.md)
3. [Test Types & Levels](03-test-types-levels.md)
4. [Defect Lifecycle & Bug Reporting](04-defect-lifecycle.md)
5. [Manual Testing in Practice](05-manual-testing-practice.md)
6. [Python Setup for Testers](06-python-setup.md)
7. [pytest Fundamentals](07-pytest-fundamentals.md)
8. [pytest Fixtures & Parametrize](08-fixtures-parametrize.md)
9. [Selenium WebDriver Basics](09-selenium-basics.md)
10. [Project — Test Plan + Automated Suite](10-project-test-suite.md)

Modules 1–5 are **manual testing** — the thinking, documentation, and process
skills that make automation worth writing. Modules 6–9 are **automation** in
Python. Module 10 combines both into a deliverable you can show in an interview.

By the end of this level you'll be able to read a requirement, derive test cases
from it, execute them, file a defect a developer can actually act on, and
automate the regression-worthy parts of that suite with pytest and Selenium.
